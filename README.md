# Transferanalyse Sommer 2026

Dieses Projekt vergleicht die Transfers der Bundesliga und der Premier League im Sommer 2026.

## Ziel

Untersucht werden unter anderem:

- Anzahl der Transfers
- Ablösesummen
- Marktwerte
- Transferausgaben und -einnahmen der Vereine
- Unterschiede zwischen Bundesliga und Premier League

## Tools

- Power BI
- Power Query
- DAX
- Python / pandas
- Excel

## Dashboard

Das Dashboard besteht aus drei Seiten:

1. Bundesliga
2. Premier League
3. Vergleich beider Ligen

## Datenquelle

Die Daten stammen von transfermarkt.de und wurden für die Analyse bereinigt.

Das Projekt wurde zu Lern- und Portfoliozwecken erstellt.
